# MongoDB Atlas (Cloud) Setup Guide

## Step-by-Step Setup

### 1. Create MongoDB Atlas Account

1. Go to: **https://www.mongodb.com/cloud/atlas**
2. Click "Try Free" or "Sign Up"
3. Sign up with Google/Email
4. Choose **FREE M0 cluster** (no credit card required)

---

### 2. Create a Cluster

1. After login, click **"Build a Database"**
2. Choose **M0 (Free Tier)**:
   - Provider: AWS, Google Cloud, or Azure (any works)
   - Region: Choose closest to your location
   - Cluster Name: `feedback-system` (or any name)
3. Click **"Create"** (takes 1-3 minutes)

---

### 3. Create Database User

1. You'll see a "Security Quickstart" popup
2. **Authentication Method**: Username and Password
3. Create credentials:
   - Username: `feedback_admin` (or your preference)
   - Password: Click "Autogenerate Secure Password" and **COPY IT**
   - Or create your own strong password
4. Click **"Create User"**

**⚠️ IMPORTANT:** Save the password somewhere safe! You'll need it for the connection string.

---

### 4. Configure Network Access

1. In the same popup, under "Where would you like to connect from?"
2. Choose **"My Local Environment"**
3. Click **"Add My Current IP Address"**
4. For easier access (development), you can also add:
   - IP Address: `0.0.0.0/0` (allows access from anywhere)
   - Description: "Allow all IPs"
   - ⚠️ This is fine for development, but for production, restrict to your server IPs

5. Click **"Finish and Close"**

---

### 5. Get Connection String

1. Click **"Connect"** button on your cluster
2. Choose **"Connect your application"**
3. Driver: **Python** (should be selected)
4. Version: **3.6 or later**
5. Copy the connection string (looks like this):

```
mongodb+srv://feedback_admin:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
```

6. **IMPORTANT:** Replace `<password>` with the actual password you created

---

### 6. Update Your .env File

Replace the MongoDB URL in your `.env` file with the Atlas connection string:

```env
# MongoDB Atlas (Cloud)
MONGODB_URL=mongodb+srv://feedback_admin:YOUR_ACTUAL_PASSWORD@cluster0.xxxxx.mongodb.net/feedback_system?retryWrites=true&w=majority

# Add database name to the URL:
# mongodb+srv://username:password@cluster.mongodb.net/feedback_system?retryWrites=true&w=majority
#                                                      ^^^^^^^^^^^^^^^^
#                                                      Add this part!

# Keep these the same
SECRET_KEY=your-super-secret-key
GROQ_API_KEY=your-groq-api-key
```

**Important changes:**
- Replace `<password>` with your actual password
- Add `/feedback_system` before the `?` to specify the database name

**Example (with fake credentials):**
```env
MONGODB_URL=mongodb+srv://feedback_admin:MySecurePass123@cluster0.ab1cd.mongodb.net/feedback_system?retryWrites=true&w=majority
```

---

### 7. Install Required Packages

```powershell
pip install motor beanie pymongo
```

---

### 8. Test Connection

```powershell
python migrate_to_mongodb.py
```

You should see:
```
✅ Connected to MongoDB successfully
```

## 🔒 Security Best Practices

### For Production:

1. **IP Whitelist:**
   - Remove `0.0.0.0/0`
   - Add only your server IPs (Vercel, Railway, etc.)

2. **Strong Password:**
   - Use autogenerated passwords
   - Never commit .env to git

3. **Database Access:**
   - Create separate users for dev/prod
   - Use different databases: `feedback_system_dev`, `feedback_system_prod`

4. **Connection String:**
   - Store in environment variables
   - Never hardcode in source code

## ⚠️ Common Issues

### Issue: "Authentication failed"
**Solution:** Check password in connection string (special characters need URL encoding)

### Issue: "IP not whitelisted"
**Solution:** Add your IP in Network Access settings

### Issue: "Connection timeout"
**Solution:** Check firewall/VPN, try adding 0.0.0.0/0 temporarily

### Issue: "Password has special characters"
**Solution:** URL encode them:
- `@` → `%40`
- `#` → `%23`
- `$` → `%24`
- `%` → `%25`
